# 安装与快速入门

当前交付目标是 Windows 10/11 x64 Alpha，不是稳定版。前往
[TaskPulse Releases](https://github.com/qingtian-4/TaskPulse/releases)，在预发布的
**Assets** 中选择 `TaskPulse_<版本>_windows_x64_setup.exe`。`Source code.zip`
是源码，不是安装包；草稿对普通用户不可见。如果尚无通过验收的安装包，请使用
[源码运行](../README.md#从源码运行)，不要把调试 EXE 当作正式下载。

MSI 是可选安装格式，不要与 NSIS 同时安装。ZIP/Portable 尚未交付。
安装版运行不需要 Rust/Bun/Node；需要 WebView2，缺少时安装器会联网下载运行时。
离线环境应先安装 WebView2；不提供绕过系统安全提示的自动操作。

## 三步开始

1. 安装、启动 TaskPulse，点击“设置监控来源”，确认并保存自己的 Agent。
2. 新来源选择“所有项目的新执行”，或设置项目白名单。WSL/SSH 独立添加，不会
   默认访问停止的发行版或所有服务器，也不自动修改 Agent 配置。
3. 发送“测试提醒”，然后在启用范围内执行任务。托盘或 `Ctrl+Shift+A` 打开面板。

思考、工具运行、等待模型响应都属于进行中；任务名称与项目名称分别展示。
本轮结束不等于项目完成。需要授权时去原 Agent 处理，TaskPulse 不替你批准。

关闭弹窗不等于已查看。通过面板右上角铃铛回查未解决请求；来源过期时显示
上次记录，只能核对／刷新，不重新弹出尚未确认的新状态。完成和失败在“待查看”
中回查，重启不重新发送旧完成提醒。

## 找不到任务时

- 先清除界面筛选；检查来源是否启用、项目是否在范围内，尤其是现有白名单。
- Windows、WSL 与 SSH 是独立来源。WSL Codex 需要运行中的发行版和 Python 3。
- SSH 先确认自己的别名可非交互连接；凭据交给系统 SSH，不填写进 Issue。
- “刷新”等待来源真实返回；来源异常／状态待更新不能当作任务结束。
- 原生格式和事件能力有版本差异，见 [支持矩阵](../README.md#支持范围)。

## 升级与卸载

备份 `~/.taskpulse/`，从托盘退出后升级。切换 EXE/MSI 安装格式前卸载旧格式。
卸载不删除 TaskPulse 用户状态；可自行保留备份。若曾明确安装 Claude Hook，
先在来源管理中撤销接入，再卸载，避免 Agent 调用不存在的程序。
