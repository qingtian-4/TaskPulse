# 豆包桌面端

TaskPulse 可以自动发现豆包桌面端的本机工作任务。也可在来源管理中添加**豆包 · 本机**，选择所有项目或设置范围。

## 数据位置

Windows 默认读取：

```text
%LOCALAPPDATA%\Doubao\User Data\Default\IndexedDB
```

自定义位置填写 IndexedDB 目录。适配依据豆包桌面 2.26.10 的原生数据结构；其他版本若改变存储格式，来源会显示待检查。Mac 豆包的存储位置与格式需以实际安装为准。

## 支持的信息

- 原生任务名称和当前执行状态。
- 只关注启动监控后发现的执行，不导入所有旧会话。
- 整轮回复的明确结束状态可以结束任务；工具或单条消息完成不等于整轮完成。
- 检查点消失、桌面端关闭或数据暂不可读时，保留上次状态并显示待更新。

豆包当前记录没有提供可可靠关联的审批请求，因此 TaskPulse 不显示豆包审批提醒，也不会自动更改权限。来源未提供的模型信息不猜测。

TaskPulse 只读这些数据，不修改数据库、代理设置或 Agent 配置。[返回兼容说明](AGENT_COMPATIBILITY.md)
