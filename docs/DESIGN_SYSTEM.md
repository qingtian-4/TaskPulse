# TaskPulse 桌面视觉系统

适用于紧凑托盘面板、来源管理与独立通知。目标是更精致的开发者桌面工具，不是 SaaS 后台模板；不增加大图表、营销卡片或无意义动画。

## 共享样式

`src/app.css` 是单一 token 来源；组件只保留布局和紧凑密度差异，不各自定义一套按钮、表单与语义色。

| 层级 | Token / class | 用法 |
|---|---|---|
| Surface | `--tp-bg` / `panel` / `card` / `raised` / `input` | 管理背景 → 主面板 → 任务/来源卡片 → hover/弹层 → 命令与输入底色 |
| 文字 | `--tp-text` / `muted` / `quiet` | 标题与正文、元信息、辅助时间；不能靠低对比度藏能力边界 |
| 品牌 | `--tp-accent` / `accent-soft` / `accent-line` | 青绿色，小型标记、选择、focus、主操作；不代表宿主验证通过 |
| 间距 / 圆角 | `--tp-space-1…6`、`--tp-radius-sm…panel` | 4/8/12/16/20/24px 基础间距；5/8/12/14px 圆角，紧凑控件可局部调整 |
| 阴影 | `--tp-shadow-card` / `shadow-window` / `glow` | 分层而不是大面积光效；不动画发光 |
| 操作 | `.tp-btn` + `data-variant=primary/ghost/danger`、`.tp-icon` | 保存/已查看、次要操作、明确移除；图标按钮保留可访问名称 |
| 状态 | `.tp-tone[data-tone]` + `.tp-chip` | 共用状态色、浅背景、边框，必须同时显示文字；颜色不是唯一状态线索 |
| 表单 / 折叠 | `.tp-theme` / `.tp-field` / `.tp-fold` | 一致的输入边框、focus、disabled 和高级说明 summary |

`focus-visible` 使用青绿色清晰轮廓；滚动条可见且 hover 加深。保留 reduced-motion 与 forced-colors 支持；没有加入大 UI 框架、字体网络请求或外部图片资源。

## 语义色不能改变事实

- 蓝色 `running`：执行、思考、工具、模型等待。
- 琥珀 `action`：明确批准/回答；中断也用琥珀提示但不因此成为审批请求。
- 青绿 `unread`：尚未查看的明确本轮结果；标记未查看不等于项目正确完成。
- 玫红 `danger`：明确任务失败，不用于来源过期。
- 灰蓝 `stale`：来源/状态待更新、未知或断开。过期失败/审批卡片首先表达不确定性。
- 绿色 `success`：可用于“本次来源读取正常”或明确结果，但标签必须说清验证对象，不能从读取/测试升级为宿主生命周期验收。

颜色选择集中于前端 `taskTone` / `sourceReadTone`，是展示映射，不修改任务、pending、通知去重或 Provider。真实 Agent 的名称、项目与活动仍来自现有数据，不添加演示名称。

概览的“进行中”包含明确待处理请求；“需处理”是它的子集，两者不能相加当任务总数。全部计数清除局部筛选，失败与结果待查看保持原有分组。选择卡片只打开详情；聚焦宿主、标记已查看是不同动作。

四步接入指示只表示配置/测试流程：选择 → 编辑能力与范围 → 保存并测试 → 等待真实任务事件。第 4 步表示本窗口本次读取已返回，**不是**真实宿主验收完成；没有为前几步画虚假的“验收成功”勾选。

## 窗口与验证

- 主面板仍不超过 440px 宽，任务总数不截断，超出高度滚动。低逻辑高度时详情限高、筛选为小浮层，避免挤掉任务列表与页脚。
- 来源管理保留已有左侧来源选择与顶部三页，不增加产品无关导航；窄窗响应式排列。
- 通知仍 320 × 132px，两行标题、单行消息，完整内容有 title；普通提醒 15 秒、确认请求无自动收起、关闭不已读等语义未改。

`scripts/visual.test.ts` 检查常用前景/背景至少 4.5:1、token 和焦点/减弱动画约束。`native-product-smoke.ts` 检查真实 WebView2 在 DPR 1/1.5/2 的布局、控件命中与截图，并加测低逻辑高度小窗。DPR 模拟不能代替真正改 Windows 显示比例、混合 DPI 跨屏、系统文字放大、屏幕阅读器和高对比度实机验收。

素材必须是原生窗口直接捕获，并标注合成事件；详见[素材说明](../assets/README.md)。
