# 任务面板与提醒

TaskPulse 的主面板回答三个问题：哪些任务仍在运行，哪些结果还没看，哪些任务需要你处理。

## 个性化设置

从任务面板的齿轮打开设置。左侧分为通用、任务面板、监控来源、通知提醒、应用更新和关于；内容较长时在右侧滚动。

- **通用**：选择跟随系统、浅色或深色，以及简体中文或 English。设置同步到任务面板、消息中心与提醒窗口。可在已安装的应用中选择登录时自动启动，并设置启动时是否展开任务面板。
- **任务面板**：选择任务或项目分组、面板密度、是否显示模型和运行时间、12～20 px 的任务字号，以及近期活动范围。
- **监控来源**：“本机”直接显示 Agent 列表，配置在对应 Agent 下展开。来源页只分本机和 SSH 服务器。本机来源沿用后端能力目录，包含 Codex、Claude Code、DeepSeek Harness、OpenCode、WorkBuddy、ZCode、Hermes、豆包及受限进程识别。SSH 服务器按 Codex / Claude Code 分别显示能力；WSL 和事件接入的底层实现及已有配置保留；tmux 是任务运行方式，不作为独立 Agent。每台服务器分为 SSH 连接、Agent、项目范围；轮询、路径、排除规则和诊断在默认折叠的高级设置中。

普通偏好自动保存；来源目录、项目范围和新增来源点击“应用更改”后生效。来源编辑期间切换栏目会保留草稿。关闭有未应用编辑的窗口时，可继续编辑、放弃或保存。已保存本机来源的启用开关即时生效；远端 Agent 开关随项目编辑一起应用。服务器暂停会记录原先启用的采集项，重启后恢复也不会额外开启其他项。

首次使用需在监控来源中点击“确认并开始监控”。主题、语言或显示设置不会替你确认来源，也不会改写已有项目范围。

检测到数据位置或会话，和本次读取成功是两回事。卡片与详情区分是否启用、读取健康和已验证的当前任务数。“已发现会话”入口展示采集目录，目录可以包含关注范围外的会话，不等于当前任务数。零启用来源或尚未首次读取时，面板不会显示读取正常。

添加 SSH 服务器依次选择系统 SSH Host（或手动输入）、检测连接与数据读取、选择 Agent 和项目。可自动关注全部项目，或勾选已发现项目并手动添加路径。检测使用系统密钥和主机校验，不保存密码、不安装远端程序。Codex SSH 需要 Python 3 和现有适配器可读取的 `~/.codex` 数据；SSH 连通不代表 Agent 可采集，读取失败时只能保存未启用的连接。Claude Code SSH 尚未适配，开关禁用，不显示成功。

## 查看任务

点击托盘图标打开面板。Windows 可按 `Ctrl+Shift+A`。面板支持按项目分组、按来源筛选，以及搜索任务标题、项目和模型。

右键菜单可显示、隐藏或固定任务面板，也可打开设置。选择“显示”会保持已打开的面板；选择“隐藏”会收起面板并取消固定。固定后，切换到其他窗口时面板继续显示。

每张任务卡显示任务名称、项目、来源上报的模型及推理强度。没有明确上报时不补猜。运行时间在来源明确结束后固定为总时长，并随任务状态保存。面板按实际内容适应最多四张卡片，更多卡片在列表内滚动；屏幕工作区不足时仍遵守系统边界。思考、工具执行和等待模型响应都属于进行中。

点击任务时，TaskPulse 会尝试切回已验证的来源窗口；窗口失效时打开任务详情。切回窗口不会自动清除任务未读状态。只有 PID、缺少进程与窗口身份的旧 Windows 状态文件和 Claude IDE 记录仍可读取，但不提供窗口聚焦。

- **进行中**：任务还在执行。
- **结果待查看**：已完成或失败，但结果尚未查看。
- **待处理**：进行中的一部分。Agent 明确请求授权、回答问题或处理额度限制时，仍算进行中；两项计数不相加。
- **状态待更新**：来源不可读或当前证据过期，保留最后已知状态。
- **固定**：你手动保留的任务。

原生 Agent 必须提供明确结束事件，TaskPulse 才会宣布结束；CPU 降低、工具返回、文件消失或日志静默不会作为结束依据。

## 来源与项目

设置窗口支持最大化和还原，普通窗口默认 960 × 704。项目选择按来源内确认的目录别名分组，保留原始范围值，不把同名的不同目录或 Windows/WSL/SSH 会话合并。

首次启动会发现本机 Agent，点击“确认并开始监控”后跟踪新执行。自动发现可在管理页开关。它不会重新启用你关闭或移除的来源，也不会覆盖已有项目白名单。

默认关注所有项目的新任务；可改为指定项目，并添加排除规则。旧项目再次执行也会出现，不需要逐个选择会话。WSL、SSH 与事件接入单独配置，Hook 安装需要明确确认。

## 未读、固定与近期活动

任务结果保留到你查看。关闭提醒只收起提醒，不代表查看任务。未读与固定状态跨重启保存。

默认按最近 7 天的执行活动显示普通关注任务，可在设置中修改。过期任务移到“较早关注”，不会删除记录；运行中任务和手动固定任务继续保留。刷新和重命名不延长活动时间。

## 提醒与消息中心

任务完成、失败或明确请求输入时分别提醒。普通结果提醒显示 15 秒，悬停暂停；明确的授权请求和结构化问题持续显示，直到处理或手动收起。同一事件不会因重启重复提醒。

点击铃铛回查消息。消息已读与任务结果已查看是独立状态；阅读消息不会批准请求。来源状态过期时，旧请求可查看，但不能据此重新弹出未经确认的提醒。

在管理页选择 TaskPulse 弹窗、系统通知或两者同时使用。系统勿扰可能隐藏系统通知。

## 更新应用

在**设置 → 应用更新**中手动检查，或保留默认自动检查。发现新版本只提示；点击安装后下载、验证签名并重启。详见[安装与更新](INSTALL.md#应用更新)。

## 默认任务视图

默认展示运行中、明确待处理、未查看结果和手动固定的任务。状态待更新的任务通过单独入口、搜索或来源筛选查看，未读与固定记录继续保留。进程扫描缺少会话身份和项目信息时产生的空白或 unknown 占位项仅供来源识别，不进入默认任务卡片；用户手动固定的记录仍可查看。任务名称本身不能用来判断子 Agent。

请求提醒的回放和实机评测见 [请求闭环评测](REQUEST_EVALUATION.md)。
