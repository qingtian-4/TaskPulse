# TaskPulse 0.2.0-alpha.2 · Windows x64

Windows Alpha for developers who run several coding agents at once. This is not
a stable release or a claim of complete approval detection for every Agent.

## Highlights / 本版重点

- Fix the actual alpha.1 MSI build failure: semantic application/tag version
  `0.2.0-alpha.2`, numeric MSI ProductVersion `0.2.0.1002`. The latter is not
  a guarantee of upgrade ordering; cross-version acceptance is still required.

- Task-first dashboard: ongoing work first; failed/ended results and stale data
  are separated. Thinking and model/tool waits do not imply completion.
- A recoverable unresolved-request inbox; reopening is explicit and never
  approves a command or acknowledges a task. Old completion notices are not
  replayed on startup. The transient popup queue is bounded to 128 entries.
- Lifecycle evidence, remote collection-segment isolation, run identities,
  long-run heartbeats, and Guardian/internal-session notification filtering.
- Native DeepSeek Harness Desktop, opt-in WSL Codex, real titles and source scopes.

## Installation / 安装

- Windows 10/11 x64: choose `TaskPulse_0.2.0-alpha.2_windows_x64_setup.exe`.
- `TaskPulse_0.2.0-alpha.2_windows_x64.msi` is an alternative installer. Do not
  install both formats side-by-side; uninstall the previous format before switching.
- Verify downloads against `SHA256SUMS.txt`. The manifest binds assets to a source
  commit. Checksums are not a Windows publisher signature. An unsigned Alpha may
  show an unknown-publisher warning; verify provenance before deciding to install.
- WebView2 is required; the installer downloads its bootstrapper if absent.
  No Rust/Bun/Node is required to run the installed app. SSH requires OpenSSH;
  supported WSL/remote collectors and wrappers may require Linux Python 3.
- Launch from the Start menu, confirm sources and scopes, and send a labelled
  test reminder. Existing scopes, unread state and pins are preserved.
- Data stays in `~/.taskpulse/`; uninstalling does not opt you into deleting it.
  Back it up before upgrading. Existing Claude Hooks or remote wrappers are not
  automatically installed or upgraded. Reconfirm optional Hook integration if needed.

## Known limitations / 已知限制

- Missing native approval events cannot be recovered from slow commands,
  permission flags, silent logs or CPU usage. No timed approval guessing.
- Claude WSL/SSH and Hermes WSL are not supported by dedicated adapters.
- Codex SSH discovery/tail windows are not equivalent to local incremental logs.
- Unified `run/attach`, optional quota collection/display, and a third-party
  executable plugin loader are not implemented. Quota refers to the local account.
- CI installation/restart/reinstall/uninstall smoke is distinct from real Agent
  approval delivery, physical clean-machine acceptance and cross-version upgrades.
  The release stays a draft until the maintainer records these remaining checks
  in the release acceptance document; no claims of unmeasured P95 latency.

Report issues with OS/Agent versions, source type and reproducible steps. Remove
private paths, prompts, commands and credentials from attachments.
