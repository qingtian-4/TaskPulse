## Install / 安装

- Windows 10/11 x64: `TaskPulse_0.2.0-alpha.4_windows_x64_setup.exe`.
- Alternative: `TaskPulse_0.2.0-alpha.4_windows_x64.msi`; uninstall the old format
  before switching between EXE and MSI. Do not install both together.
- Verify `SHA256SUMS.txt` and the source SHA manifest. Unsigned Alpha: hashes are
  not a publisher signature; verify provenance before accepting system warnings.
- WebView2 is required and bootstrapped online if absent. No Rust/Bun/Node or CI
  test helper is required by the installed application. Supported Linux/WSL/SSH
  collectors can need Python 3/OpenSSH. Back up `~/.taskpulse/` before upgrading.
- Confirm sources/scopes and send a labelled test reminder. Uninstall preserves
  user state; Agent hooks/wrappers remain explicit, reversible opt-ins.

## Release gates / 验收边界

CI installation is not clean-machine, cross-version upgrade, real Agent approval,
editor-focus or long-run latency acceptance. Keep the release a draft until the
maintainer records remaining gates in [RELEASING.md](../RELEASING.md).
No dedicated Claude WSL/SSH or Hermes WSL adapter, unified run/attach, executable
plugin marketplace or independent quota toggles. Missing approval events cannot
be recovered from command flags or silence. Quota refers to the local account.
