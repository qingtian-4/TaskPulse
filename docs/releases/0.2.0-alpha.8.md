# TaskPulse 0.2.0-alpha.8

## Changes

- Display the reported model alongside task titles, projects and elapsed time.
- Use a compact tray panel that fits laptop work areas and high-DPI displays.
- Discover supported local Agent sources automatically after first-run confirmation, while preserving existing source choices and project scopes.
- Read native ZCode sessions, projects, models and task states.
- Check for application updates automatically; download, verify and install only after a user click.
- Provide Windows EXE/MSI, macOS Apple Silicon/Intel DMG packages and one-command installation.

## Installation

Choose one Windows installer format, or the DMG matching your Mac architecture. Installed applications do not require Bun or Rust. Windows uses WebView2 and can download the runtime if missing.

Updates retain `~/.taskpulse/` settings and task state. For manual replacement, quit TaskPulse first. Keep a backup when changing installation formats.

Updater artifacts use TaskPulse's update signature. This is separate from Windows publisher signing and Apple notarization. Packages without OS publisher signing may show normal system security prompts; TaskPulse does not bypass those checks.
