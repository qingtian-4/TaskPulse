# TaskPulse 0.2.0-alpha.8 · test candidate

This candidate includes the task identity, explicit approval observer, atomic
attention persistence, single-instance GUI and bounded process fixes described in
[CHANGELOG](https://github.com/qingtian-4/TaskPulse/blob/main/CHANGELOG.md).
It is intended for Windows and Apple Silicon acceptance, not a stable support claim.

## Downloads

- Windows x64: `TaskPulse_0.2.0-alpha.8_windows_x64_setup.exe` (recommended),
  or `TaskPulse_0.2.0-alpha.8_windows_x64.msi`. Choose one installer format.
  Verify `SHA256SUMS.txt` and the source SHA in `release-manifest.json`.
- Apple Silicon: `TaskPulse_0.2.0-alpha.8_macos_arm64.dmg` after the independent
  macOS workflow passes. Verify `macos-arm64-SHA256SUMS.txt` and
  `macos-arm64-manifest.json`; a Windows draft alone does not include or validate a DMG.

Quit the previous TaskPulse instance before replacing it. Preserve and back up
`~/.taskpulse/`. Installed applications do not require Rust, Bun or a source clone.
Windows requires WebView2 and uses the online bootstrapper when it is missing.
The application version is `0.2.0-alpha.8`; MSI metadata is `0.2.0.1008`.

Windows installers are unsigned. macOS packages use an ad-hoc signature and are
not Apple notarized. Gatekeeper/download acceptance remains a manual test; hashes
identify artifacts but do not authenticate a publisher. Do not disable system-wide
security settings to install a test build.

## Acceptance boundaries

Windows release CI requires complete quality/security checks and independent
NSIS/MSI installed-app/native IPC checks, twice each on fresh runners. macOS runs
native unit tests, clippy, frontend checks, DMG mount/copy, signature/architecture
and version verification, plus isolated startup, second-launch and restart checks.
macOS process survival does not prove rendering, tray interaction, focus, notifications,
real Agent approval or downloaded-app Gatekeeper acceptance. These remain explicit
manual checks in [the Mac guide](https://github.com/qingtian-4/TaskPulse/blob/main/docs/MACOS_DEVELOPMENT.md).

Cross-version/format migration, WebView2-absent/offline installs and sustained real
Agent latency need separate evidence. Keep the release a draft until the recorded
manual gates and dependency-license review have been completed or explicitly reviewed
by the maintainer. Never substitute the old Alpha.7 results for these new binaries.

Security reports retain lower-severity frontend findings and Rust maintenance /
unsoundness warnings. No ignored-advisory baseline is used. Exported dependency
notices mark missing license texts for review; inventory generation is not a license
compliance approval. See [release gates](https://github.com/qingtian-4/TaskPulse/blob/main/docs/RELEASING.md).
