# TaskPulse 0.2.0-alpha.5 · Windows x64

Acceptance history: run 38690260098 passed the complete NSIS lifecycle. MSI then
reused NSIS's retained install-directory preference instead of the harness's
assumed fresh directory. Draft creation was blocked. Alpha.6 tests each format
on its own fresh runner; cross-format migration is a separate manual gate.

Windows-first Alpha for monitoring multiple coding agents at a glance, with
one-shot turn-end/input/failure reminders. Not a stable or universal Agent release.

## Changes

Retains the [dashboard and source capabilities](0.2.0-alpha.3.md) and correct
native process exit codes. Fixes installer acceptance identity checks using final
file-handle paths, including Windows 8.3 aliases, without allowing unrelated
processes. IPC evidence is a single checked object; restart waits for the old CDP
endpoint to close. Installers retain normal permissions; app tests run as a user.
Semantic app/tag version `0.2.0-alpha.5`, numeric MSI version `0.2.0.1005`.
Prior failed tags remain unchanged. MSI's fourth field is not an upgrade guarantee.

## Installation

- Windows 10/11 x64: `TaskPulse_0.2.0-alpha.5_windows_x64_setup.exe`.
- Alternative: `TaskPulse_0.2.0-alpha.5_windows_x64.msi`. Uninstall the previous
  format before switching; do not install EXE and MSI together.
- Verify `SHA256SUMS.txt` and the source SHA manifest. This Alpha is unsigned;
  checksums are not a publisher signature. Verify provenance before installing.
- WebView2 is required; missing runtimes are bootstrapped online. No Rust/Bun/Node
  or CI helper is required by the installed app. SSH/Linux collectors can require
  OpenSSH/Python 3. Back up `~/.taskpulse/` before upgrading; uninstall keeps state.
- Confirm sources/scopes and send a labelled test reminder. Agent hook/wrapper
  integration remains explicit, reversible and never silently upgraded.

## Acceptance boundaries

CI install/restart/reinstall/uninstall does not prove clean-machine support,
cross-version upgrades, real Agent approval delivery, focus or long-run latency.
Keep this a draft until [manual release gates](../RELEASING.md) are recorded.
No dedicated Claude WSL/SSH or Hermes WSL adapter, universal run/attach, executable
plugin loader or independent quota toggle. Approval events are never guessed
from silence/flags. Quota is for the local account; SSH snapshots are bounded.

Report reproducible issues without credentials/private task content. Derived from
AgentTray under MIT; original attribution and commit history are preserved.
