# TaskPulse v1.0.0

## English

The first public TaskPulse release brings Agent tasks into one tray panel.

- Follow task status, reported models and elapsed time across supported local agents, WSL and SSH sources.
- Receive reminders for completed work, failures and explicit input or approval requests, with unread results preserved across restarts.
- Customize light/dark appearance, English/Simplified Chinese, login startup and monitoring sources in one settings window.
- Install on Windows or macOS using a package or one command, then check for signed updates in the app.

**Windows:** Windows 10/11 x64; EXE is recommended for user installation, while MSI requires the appropriate administrator permissions. WebView2 is installed if missing.

**macOS:** macOS 13.3 or later, with separate Apple Silicon and Intel DMGs.

Windows packages have no publisher certificate, and macOS packages are ad-hoc signed without Apple notarization. Normal system security prompts may appear; follow the [installation guide](https://github.com/qingtian-4/TaskPulse/blob/main/docs/INSTALL.md). Update signatures and SHA-256 checksums are provided separately. MSI upgrades may require administrator approval; use the same installer format for future upgrades.

## 简体中文

TaskPulse 首次公开发布，将多个 Agent 的任务集中到托盘面板。

- 统一查看已适配的本机 Agent、WSL 和 SSH 来源的任务状态、上报模型与运行时间。
- 完成、失败和明确提问或审批请求分别提醒，未查看结果可跨重启保留。
- 在设置中自定义浅色或深色外观、中英文、登录启动及监控来源。
- Windows 和 macOS 均提供安装包及一条命令安装，并支持应用内签名更新。

**Windows：**支持 Windows 10/11 x64，推荐 EXE 用户安装；MSI 需要相应管理员权限，缺少 WebView2 时由安装器补齐。

**macOS：**需要 macOS 13.3 或更高版本，Apple Silicon 与 Intel 使用各自的 DMG。

Windows 包尚无发布者证书，macOS 包采用临时签名且未经过 Apple 公证，首次安装可能出现系统安全提示，请按[安装指南](https://github.com/qingtian-4/TaskPulse/blob/main/docs/INSTALL.md)操作。更新签名与 SHA-256 校验文件单独提供。MSI 升级可能需要管理员批准，后续升级请保持安装格式一致。
