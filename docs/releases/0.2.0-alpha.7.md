# TaskPulse 0.2.0-alpha.7 · Windows x64 candidate

Monitor several coding-agent tasks without repeatedly switching conversations.
TaskPulse shows native titles, project/source, current activity and explicit
turn-end/input/failure reminders. This is an Alpha, not a stable universal plugin.

## Changes

- Add dynamic task attention across configured environments, native session titles,
  clearer execution phases and separate explicit task/input reminders.
- Improve incremental parsing, bounded caches and durable event recovery without
  interpreting silence or tool returns as Agent completion.
- Add partial, explicitly graded local event adapters and reversible Hook consent
  flows; no real Kimi/TRAE/ZCode/WorkBuddy host certification is claimed.
- Refine the compact desktop dashboard, source manager and narrow reminders;
  screenshots use the real native renderer with clearly labelled synthetic input.

- Update the SvelteKit 2 / Svelte 5 / Vite 8 graph and vulnerable transitive packages.
- Update Windows notifications and plist to remove the old quick-xml instances;
  refresh fixed anyhow/event-listener/rand entries and the yanked fastrand version.
- Gate new builds on moderate-or-higher frontend advisories, Rust vulnerabilities
  and yanked dependencies, and a redacted complete Git history scan. Security
  tooling is checksum-pinned, read-only and not installed with the application.
- Keep every real NSIS/MSI acceptance check on independent Windows runners.

## Installation (only after assets and acceptance exist)

Choose one: `TaskPulse_0.2.0-alpha.7_windows_x64_setup.exe` or
`TaskPulse_0.2.0-alpha.7_windows_x64.msi`. Do not install both formats together.
Verify `SHA256SUMS.txt` and `release-manifest.json`, including the source commit.
The app version is `0.2.0-alpha.7`; MSI numeric metadata is `0.2.0.1007`.
This candidate is unsigned; a hash is not a publisher signature.

Windows 10/11 x64 and WebView2 are required. The installed app needs no Rust,
Bun, Node or audit tools. WebView2 is bootstrapped online if absent. Back up
`~/.taskpulse/`, exit the tray before upgrading, and explicitly confirm sources.
Uninstall preserves user state. Hooks remain explicit and reversible.

## Security and acceptance boundaries

The frontend audit still reports one low-severity cookie dependency from Kit 2.
Rust retains maintenance warnings and two unsoundness warnings (Linux glib and
legacy rand). These are recorded risks, not silently ignored or declared fixed.
The static desktop build does not run a SvelteKit cookie server. Windows does not
build glib; the legacy rand feature graph does not enable its advisory's log
feature. Reassess if platforms, features or server functionality change.

Alpha.6's installer success does not validate these new binaries. New CI,
independent installed-app tests, clean-machine/WebView2-absent, cross-version/
format migration, real Agent events, focus and sustained latency need their own
evidence. Keep this candidate a draft; do not publish merely because it builds.
See the [publication checklist](https://github.com/qingtian-4/TaskPulse/blob/main/docs/OPEN_SOURCE_CHECKLIST.md)
and [manual gates](https://github.com/qingtian-4/TaskPulse/blob/main/docs/RELEASING.md).

No universal run/attach, dynamic plugin marketplace, dedicated Claude WSL/SSH or
Hermes WSL adapter is promised. Source outage and quiet thinking never imply task
completion. Derived from AgentTray under MIT, with original attribution preserved.
