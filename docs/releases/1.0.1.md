# TaskPulse v1.0.1

## English

- Fix macOS command-line installation when a release manifest omits optional metadata fields.
- Preserve version, architecture, SHA-256, signature and quarantine checks during installation.

Use the [installation guide](https://github.com/qingtian-4/TaskPulse/blob/main/docs/INSTALL.md) or rerun the README command to install the latest version. Windows packages have no publisher certificate; Mac packages use ad-hoc signing without Apple notarization, so normal OS security confirmation may be required. Existing settings and task state are retained.

## 简体中文

- 修复 macOS 命令行安装在发布清单缺省可选字段时被错误拒绝的问题。
- 安装过程继续核对版本、架构、SHA-256、签名并保留系统隔离属性。

按[安装指南](https://github.com/qingtian-4/TaskPulse/blob/main/docs/INSTALL.md)操作，或重新执行 README 中的安装命令即可安装最新版。Windows 包尚无发布者证书，Mac 包采用临时签名且未经过 Apple 公证，首次打开可能需要系统安全确认；已有配置与任务状态保留。
