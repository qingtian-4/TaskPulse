# TaskPulse 0.2.0-alpha.6 · Windows x64

Windows-first Alpha for monitoring several coding agents at a glance, with
one-shot turn-end/input/failure reminders. Not a stable or universal Agent release.

## Changes

Includes the [task-first dashboard and source capabilities](0.2.0-alpha.3.md),
recoverable unresolved prompts and strict lifecycle evidence. Thinking stays
running; source faults and internal Guardian sessions do not become completions.

Installer acceptance now gives NSIS and MSI independent fresh Windows runners.
Both must pass real install/version/UI/IPC/restart/reinstall/uninstall checks.
Retained installation preferences are preserved, not deleted to satisfy a test;
cross-format migration is a separate gate. Native tests retain exact process
exit codes, final-path ownership and single-object IPC evidence.
Semantic version `0.2.0-alpha.6`, MSI version `0.2.0.1006`; old tags are unchanged.
MSI's fourth field does not guarantee cross-version upgrade ordering.

## Installation

- Windows 10/11 x64: `TaskPulse_0.2.0-alpha.6_windows_x64_setup.exe`.
- Alternative: `TaskPulse_0.2.0-alpha.6_windows_x64.msi`. Choose one format; do not
  install both. Uninstall before switching; directory preferences can be retained.
- Verify `SHA256SUMS.txt` and the source SHA manifest. This Alpha is unsigned;
  hashes are not a publisher signature. Verify provenance before installing.
- WebView2 is required and bootstrapped online if absent. No Rust/Bun/Node or CI
  helper is required by the installed app. Linux/SSH collectors can need Python 3
  or OpenSSH. Back up `~/.taskpulse/`; uninstall preserves user state.
- Confirm sources/scopes and send a labelled reminder. Agent hook/wrapper
  integration remains explicit, reversible and never silently upgraded.

## Remaining gates and limits

CI acceptance is not clean-machine/WebView2-absent, cross-version/cross-format
upgrade, real Agent approval delivery, editor-focus or long-run latency proof.
Keep this release a draft until [manual gates](../RELEASING.md) are recorded.
No dedicated Claude WSL/SSH or Hermes WSL adapter, universal run/attach, executable
plugin loader or independent quota toggle. Approval is not guessed from silence
or flags. Quota is for the local account; remote log snapshots are bounded.

Report reproduction steps without credentials or private task content. Derived
from AgentTray under MIT; original attribution and commit history are preserved.
