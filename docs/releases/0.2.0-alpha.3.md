# TaskPulse 0.2.0-alpha.3 · Windows x64

Windows Alpha for running several coding agents without repeatedly switching
windows to check them. Not a stable release or universal Agent support promise.

## Highlights / 本版重点

- Task-first dashboard with real titles, separate projects, observable activity
  and one-shot end/input/failure reminders. Thinking remains running.
- Recover unresolved explicit requests from the bell inbox without approving,
  acknowledging or replaying old lifecycle notifications.
- Native DeepSeek Harness Desktop, opt-in WSL Codex, configured SSH/tmux sources,
  stale-source visibility and internal Guardian-session filtering.
- Numeric MSI metadata stays separate from semantic app/tag versions:
  `0.2.0-alpha.3` / `0.2.0.1003`; this does not guarantee upgrade ordering.
- Fix elevated-runner WebView2 acceptance: install with normal permissions,
  validate the installed app at medium integrity, and retain failure evidence.
  The Alpha.2 installers built, but its native acceptance failed; its tag is kept.

## Installation / 安装

- Windows 10/11 x64: choose `TaskPulse_0.2.0-alpha.3_windows_x64_setup.exe`.
- Alternative: `TaskPulse_0.2.0-alpha.3_windows_x64.msi`. Do not install both
  formats together; uninstall the previous format before switching.
- Verify `SHA256SUMS.txt` and the source SHA manifest. This Alpha is unsigned;
  checksums are not a publisher signature. Verify provenance before installing.
- WebView2 is required; the installer downloads its bootstrapper if absent.
  The installed application needs no Rust, Bun, Node or CI test helper.
  SSH needs OpenSSH; supported Linux/WSL collectors can require Python 3.
- Confirm sources/scopes, send a labelled test reminder and start a real task.
  Existing state stays in `~/.taskpulse/`; back it up before upgrading.
- Uninstall keeps user state. Agent hooks/wrappers are never silently installed
  or upgraded; optional integration remains an explicit, reversible choice.

## Known limitations / 已知限制

- No timed approval guesses from silence, command flags or CPU usage.
- No dedicated Claude WSL/SSH or Hermes WSL adapter; SSH log snapshots are not
  equivalent to local incremental collection. Quota refers to the local account.
- Unified run/attach, a third-party executable plugin loader and independent
  quota toggles remain unimplemented.
- CI install/restart/reinstall/uninstall is not clean-machine, cross-version
  upgrade, real Agent approval delivery, focus or long-run latency acceptance.
  Keep this release a draft until the maintainer records remaining manual gates.
