# TaskPulse v0.0.1

## 简体中文

计划版本，尚未发布。此版本从当前 TaskPulse 实现重新编号，保留原项目的版权、许可及提交历史。

### 新增与改进

- 在固定尺寸设置窗口中管理本机来源及多个 SSH 服务器，支持三步连接向导、连接与数据读取分别检测，以及全部项目／指定项目范围。
- 本机列表来自现有能力目录，保留 Codex、Claude Code、DeepSeek Harness、OpenCode、WorkBuddy、ZCode、Hermes、豆包及受限进程识别。
- 保留未读、固定、明确请求及通知去重的恢复能力；读取异常不推断任务完成。

### 修复

- 设置齿轮及默认设置入口打开“通用”，来源相关入口仍打开“监控来源”。
- 移除设置窗口左下角的冗余文案，通过系统浏览器打开项目及许可链接。
- 安全工具使用后清理解压副本，保留经过摘要校验的下载包。

### 兼容与已知限制

- 来源 ID、配置格式、应用标识及签名更新校验保持兼容，不修改真实 Hook 或审批策略。Claude Code SSH 尚未适配；Claude 原生提问尚未支持。
- 版本号 0.0.1 小于已发布的 1.0.0／1.0.1，旧应用不会将它识别为正常升级。旧版本及附件暂时保留；迁移与下线应在安装、签名及平台验收完成后单独执行，不绕过降级或系统安全检查。
- 真实来源大样本误报／漏报、实际渲染 P95、宿主返回成功率、总体资源、MSI UAC 及缺少真机的平台验收仍单独保留，不以回放或少量样本替代。
- 既有版本附件保持完整；新 0.0.x 系列复用紧凑发布布局，同时保留 MSI 更新兼容包、签名验证和许可资料。实际下载链接由发布流水线根据已验证产物生成。

## English

Planned, not published. This version renumbers the current TaskPulse implementation while preserving copyright, licenses and commit history.

### Added and changed

- Manage local sources and multiple SSH servers in the fixed-size settings window, with a three-step connection wizard, separate connection/data checks, and all-project or selected-project scopes.
- Populate local sources from the existing capability catalog, retaining Codex, Claude Code, DeepSeek Harness, OpenCode, WorkBuddy, ZCode, Hermes, Doubao and limited process discovery.
- Preserve unread results, pins, explicit requests and notification deduplication across recovery. Read failures never imply task completion.

### Fixed

- The panel gear and default settings entry open General; source-specific actions still open Sources.
- Remove redundant settings sidebar copy and open project/license links in the system browser.
- Remove extracted security tools after use while retaining checksum-verified downloads.

### Compatibility and limitations

- Source IDs, configuration format, application identity and signed-update verification remain compatible. Real hooks and approval policies are unchanged. Claude Code over SSH and native Claude questions remain unsupported.
- Version 0.0.1 is lower than published versions 1.0.0/1.0.1, so old applications will not recognize it as a normal update. Existing releases and assets remain available pending a separate migration/retirement decision and installer/platform validation. Downgrade and operating-system security checks are not bypassed.
- Large real-source evaluations, actual rendering P95, host-return success, overall resource acceptance, MSI UAC and unavailable physical-platform checks remain separate gates.
- Existing assets remain intact. The new 0.0.x series reuses the compact layout while retaining MSI updates, signature verification and license materials. The release workflow generates links from validated artifacts.
