# TaskPulse v0.0.1

不必盯着 Agent，需要你时再回来。

TaskPulse 首次正式发布，重点关注 Codex、Claude Code 的本机任务。

## 新增

- 在托盘中查看多个 Coding Agent 的运行、待处理与未读结果；本机来源自动发现，SSH 服务器按需连接。
- 本机 Agent 直接配置，SSH 三步向导分别检查连接、数据读取与项目范围。连接成功不会冒充读取成功。
- 支持 Codex、Claude Code、DeepSeek Harness 等原生来源，并增加 Kimi Code 与 Qoder 读取；Trae 明确标识当前存储格式限制。

## 改进

- 显示来源报告的模型与推理强度，保留明确起止时间的总时长。面板适应最多四张完整卡片，更多任务内部滚动，任务默认字号为 12 px，可自行调整。
- 明确请求按 ID 匹配解除；未读结果、固定与未解决请求跨重启恢复。数据不完整、损坏或超限时保留可信状态。
- 结果卡片只显示状态和内容，在任务详情中可手动标记已查看。位置和未读圆点相邻，面板、提醒和托盘统一用蓝色表示进行中、琥珀色表示待处理、青绿色表示待查看。
- 本机来源区分未检测到、读取正常但暂无近期会话、仅支持会话目录。可选 Hook 随对应 Agent 配置；通用事件和进程检测放在高级入口。
- 中英文界面、浅色与深色主题，本地运行，按需启用提醒与声音。

## 修复

- 修复 Windows 托盘点击、失焦与设置窗口的焦点竞争，改进来源状态表达和项目路径归并。
- 打开设置时立即显示框架和加载提示。
- 正式版更新不再提示首发前的测试版本。

## 安装与兼容

[安装说明](https://github.com/qingtian-4/TaskPulse/blob/v0.0.1/docs/INSTALL.md) · [支持的 Agent 与平台](https://github.com/qingtian-4/TaskPulse/blob/v0.0.1/README.md#支持的-agent)

从本页顶部选择 Windows x64、Windows ARM64、macOS Apple Silicon 或 macOS Intel 安装包。发布附件包括校验和、签名及依赖许可资料。安装过旧测试版本的用户请退出并卸载旧应用，再手动安装 v0.0.1。卸载时选择保留本机配置与任务状态。

## 已知限制

Claude 原生提问及 Claude SSH 尚未支持。Qoder 原生审批与提问尚未支持；Trae 当前只提供公开会话发现。聚焦宿主不代表精确会话跳转，关闭提醒不标记已读、不代批准。

## English

Stop watching your agents. Come back when they need you.

TaskPulse's first official release focuses on local Codex and Claude Code tasks.

### Added

- Monitor running tasks, explicit requests and unread results in one tray panel. Discover local readers and connect SSH servers on demand.
- Configure local agents inline. The SSH wizard checks connection, data access and project scope separately.
- Read native Codex, Claude Code, DeepSeek Harness and other sources, including Kimi Code and Qoder. Trae shows its current storage limitations explicitly.

### Changed

- Show reported models and reasoning effort, and retain duration from explicit start/end evidence. Fit up to four cards with internal scrolling and an adjustable default task text size of 12 px.
- Match request resolutions by ID; restore unread results, pins and pending requests across restarts. Incomplete, corrupt or oversized reads preserve trusted state.
- Result cards group location and unread indicators. The panel, reminders and tray use blue for ongoing work, amber for requests and teal for unread results. Mark a result as viewed in task details.
- Local sources distinguish missing data, healthy reads without recent sessions, and catalog-only support. Optional hooks are managed under their agent; generic events and process detection have separate advanced controls.
- English/Chinese interface, light/dark themes and optional notifications and sound. Conversations stay local.

### Fixed

- Fix Windows tray and settings focus races, improve source health and merge verified project-path aliases.
- Show the settings layout and loading status as soon as the window opens.
- Keep prelaunch test versions out of official update prompts.

### Installation and compatibility

[Install](https://github.com/qingtian-4/TaskPulse/blob/v0.0.1/README.en.md#install) · [Supported agents](https://github.com/qingtian-4/TaskPulse/blob/v0.0.1/README.en.md#supported-agents)

Choose Windows x64, Windows ARM64, macOS Apple Silicon, or macOS Intel from the downloads above. The release includes checksums, signatures, and dependency licenses. If you installed an earlier test build, quit and uninstall it before installing v0.0.1 manually. Choose to keep local settings and task state when uninstalling.

### Known limitations

Native Claude questions and Claude SSH are unsupported. Qoder native approvals/questions are unsupported; Trae currently provides public session discovery only. Host focus does not establish an exact session jump. Dismissing a reminder never marks it read or approves it.
