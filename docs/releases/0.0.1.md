# TaskPulse v0.0.1

不必盯着 Agent，需要你时再回来。

TaskPulse 首次正式发布，重点关注 Codex、Claude Code 的本机任务。

## 新增

- 在托盘中查看多个 Coding Agent 的运行、待处理与未读结果；本机来源自动发现，SSH 服务器可按需添加。
- 本机 Agent 直接配置，SSH 三步向导分别检查连接、数据读取与项目范围。保存期间锁定向导，保存失败后可继续编辑草稿。
- 支持 Codex、Claude Code、DeepSeek Harness 等原生来源，并增加 Kimi Code 与 Qoder 读取；Trae 明确标识当前存储格式限制。

## 改进

- 显示来源报告的模型与推理强度，保留明确起止时间的总时长。面板适应最多四张完整卡片，更多任务内部滚动，任务默认字号为 12 px，可自行调整。
- 明确请求按 ID 匹配解除；未读结果、固定与未解决请求跨重启恢复。数据不完整、损坏或超限时保留可信状态。
- 结果卡片只显示状态和内容，在任务详情中可手动标记已查看。位置和未读圆点相邻，面板、提醒和托盘统一用蓝色表示进行中、琥珀色表示待处理、青绿色表示待查看；正常结束的任务统一显示「本轮结束」。
- 监控来源首页只列出本机 Agent 和 SSH 服务器入口，旧来源配置保留。
- 中英文界面、浅色与深色主题，本地运行，按需启用提醒与声音。

## 修复

- 修复 Windows 托盘点击、失焦与设置窗口的焦点竞争，改进来源状态表达和项目路径归并。
- 打开设置时显示加载提示，再次打开已最小化的设置会恢复窗口。
- 修复 macOS 旧版 ZCode 和 Hermes 的读取兼容问题；ZCode 可以选择桌面项目，Hermes 可关注未关联项目的会话。
- Kimi Code 显示实际模型及其本机显示名，Hermes 显示会话的推理设置，ZCode 显示本轮的推理档位。
- Qoder 在分批读取时继续追踪长日志和繁忙会话，已知任务的结束记录能在后续轮次读取。

## 安装与兼容

应用内置 SQLite 已更新，修复打开特制数据库及其 WAL 时可能泄露内存数据的问题（RUSTSEC-2026-0459）。

[安装说明](https://github.com/qingtian-4/TaskPulse/blob/v0.0.1/docs/INSTALL.md) · [支持的 Agent 与平台](https://github.com/qingtian-4/TaskPulse/blob/v0.0.1/README.md#支持的-agent)

从本页顶部选择 Windows x64、Windows ARM64、macOS Apple Silicon 或 macOS Intel 安装包。发布附件包括校验和、签名及依赖许可资料。已安装 v1.0.1 等旧测试版本时，请退出并卸载旧应用，再手动安装 v0.0.1。卸载时选择保留本机配置与任务状态。

## 已知限制

Windows 与 macOS 暂停豆包监控。Claude Code 可通过 SSH 读取运行和结束状态；远端审批和原生提问尚未支持。Qoder 原生审批与提问尚未支持；Trae 当前只提供公开会话发现。聚焦宿主不代表精确会话跳转，关闭提醒不标记已读、不代批准。

## English

Stop watching your agents. Come back when they need you.

TaskPulse's first official release focuses on local Codex and Claude Code tasks.

### Added

- Monitor running tasks, explicit requests and unread results in one tray panel. Discover local agents and add SSH servers as needed.
- Configure local agents inline. The SSH wizard checks connection, data access and project scope separately, and keeps your draft if saving fails.
- Read native Codex, Claude Code, DeepSeek Harness and other sources, including Kimi Code and Qoder. Trae shows its current storage limitations explicitly.

### Changed

- Show reported models and reasoning effort, and retain duration from explicit start/end evidence. Fit up to four cards with internal scrolling and an adjustable default task text size of 12 px.
- Match request resolutions by ID; restore unread results, pins and pending requests across restarts. Incomplete, corrupt or oversized reads preserve trusted state.
- Result cards group location and unread indicators. The panel, reminders and tray use blue for ongoing work, amber for requests and teal for unread results. Normal finishes share the label “Turn ended.” Mark a result as viewed in task details.
- The Sources page lists local agents and SSH servers and preserves previously configured sources.
- English/Chinese interface, light/dark themes and optional notifications and sound. Conversations stay local.

### Fixed

- Fix Windows tray and settings focus races, improve source health and merge verified project-path aliases.
- Show the settings layout while it loads and restore the window when you reopen it from a minimized state.
- Restore compatibility with older ZCode and Hermes databases on macOS. ZCode desktop projects can be selected, and Hermes sessions can be followed without a project.
- Show the actual model and local display name for Kimi Code, and show recorded reasoning effort for Hermes and ZCode.
- Resume long Qoder journals across batches and rotate busy sessions so their turn results can be read.

### Installation and compatibility

Bundled SQLite includes the fix for possible memory disclosure when opening a crafted database and its WAL (RUSTSEC-2026-0459).

[Install](https://github.com/qingtian-4/TaskPulse/blob/v0.0.1/README.en.md#install) · [Supported agents](https://github.com/qingtian-4/TaskPulse/blob/v0.0.1/README.en.md#supported-agents)

Choose Windows x64, Windows ARM64, macOS Apple Silicon, or macOS Intel from the downloads above. The release includes checksums, signatures, and dependency licenses. If you installed v1.0.1 or another earlier test build, quit and uninstall it before installing v0.0.1 manually. Choose to keep local settings and task state when uninstalling.

### Known limitations

Doubao monitoring is paused on Windows and macOS. SSH monitoring for Claude Code covers running and completed turns; remote approvals and native questions are unsupported. Qoder native approvals/questions are unsupported; Trae currently provides public session discovery only. Host focus does not establish an exact session jump. Dismissing a reminder never marks it read or approves it.
