# TaskPulse v1.1.0

## 简体中文

不必盯着 Agent，需要你时再回来。

### 新增

- 来源设置优先展示已检测或已配置的 Agent，未检测的支持列表可展开，WSL、SSH、Hook/MCP 和自定义目录集中在高级入口。
- 展示来源的发现、模型、开始/结束、审批、提问和返回能力，并区分支持平台与已验证平台。
- 增加请求闭环回放与评测工具、同一提交的发布验收清单，以及包含可验证 WebView2 子进程的 Windows 资源采样。

### 改进

- 分别展示来源支持、检测到数据、已启用、读取健康、会话和当前任务，修正空数据及首次读取时的状态表达。
- 为兼容状态文件增加单文件和单轮读取预算，为 Claude 日志增加跨会话准入与容量保护。超限、损坏或读取失败时保留可信状态并报告降级。
- 保留待处理请求、未读结果和固定状态的恢复能力，减少 Claude 准入检查的重复 I/O。
- 同步安装、更新、能力、故障排查与中英文开发说明，保留从源码构建入口。开发包省略调试符号。
- 补充新版 Windows 界面的中英文面板、三种提醒截图及示例操作演示，提醒截图横向排列。

### 修复

- 修复 Windows 托盘失焦后松开鼠标又打开的竞争，增加右键“设置”，使“显示”和“隐藏”保持单一动作。
- 修复主面板迟到的就绪事件抢走设置窗口焦点，以及扫描结果全部去重后误显示未检测到数据。
- 修复标准账户身份探针冷启动阻塞、前端构建资源不匹配，以及不完整来源恢复时丢失待处理请求的问题。

### 安全与兼容

TaskPulse 不会代批准、修改真实 Agent Hook 或更改审批策略。返回窗口和关闭提醒不会自动标为已读。现有来源 ID、配置和任务状态继续兼容。签名更新校验及系统安全检查保留。

当前版本保留完整发布附件。后续版本将合并发布清单、校验和及依赖许可资料，MSI 兼容更新包继续保留。

### 安装与升级

从本页顶部选择对应系统的安装包，或使用 [README 安装命令](https://github.com/qingtian-4/TaskPulse#安装)。已有用户也可在“设置 → 应用更新”中检查并确认安装。Windows 安装包尚无发布者证书；Mac 使用 ad-hoc 签名，尚未经过 Apple 公证。请按系统正常安全流程确认，详见[安装说明](https://github.com/qingtian-4/TaskPulse/blob/main/docs/INSTALL.md)。

### 已知限制与待验收

- Codex 审批需要现有明确事件通道。Claude 原生提问尚未支持；没有可靠跳转接口的来源回退到详情或复制。
- 真实来源按 Agent、版本、平台分组的大样本误报/漏报、渲染 P95、宿主返回成功率和总体资源验收仍待完成。少量已确认样本与固定回放不能替代这些结果。
- 普通 MSI 交互式 UAC、Windows ARM64 实机、双架构 Mac 首次启动与信任、高 DPI、多屏和实际睡眠恢复仍需对应硬件验收。

## English

Stop watching your agents. Come back when they need you.

### Added

- Source settings prioritize detected/configured agents, with expandable supported agents and advanced WSL, SSH, Hook/MCP and custom-directory connections.
- Capability metadata for discovery, models, turn start/end, approvals, questions and return actions, separating supported from verified platforms.
- Request replay/evaluation tools, a same-commit release checklist, and Windows resource sampling including verified WebView2 descendants.

### Changed

- Separate support, data detection, enablement, read health, sessions and current tasks, including empty and initial-read states.
- Bound compatible status reads per file and per collection, with cross-session Claude journal admission and capacity safeguards. Limits, corruption and read failures preserve trusted state and report degraded health.
- Preserve pending requests, unread results and pinned tasks across restarts, while reducing repeated Claude admission I/O.
- Update installation, upgrades, capabilities, troubleshooting and bilingual development instructions, retaining Build from source. Development builds omit debug symbols.
- Add Chinese and English Windows dashboard screenshots, three notifications in one row, and a sample interaction demo.

### Fixed

- Windows tray release/focus races, with a Settings menu entry and idempotent Show/Hide actions.
- Late popup readiness stealing settings focus and scanner detection disappearing when all records are deduplicated.
- Cold-start stalls in standard-account probes, mismatched frontend bootstrap assets and pending-request recovery after incomplete reads.

### Security and compatibility

TaskPulse never approves requests for you or changes real Agent hooks or approval policies. Returning to a window or dismissing a notification does not mark a task read. Existing source IDs, configuration and task state remain compatible. Signed updater verification and OS security checks remain required.

This version retains complete release attachments. Future versions consolidate manifests, checksums and dependency/license material while retaining the MSI compatibility update package.

### Installation and upgrade

Choose your system's installer at the top of this page, use the [README installation commands](https://github.com/qingtian-4/TaskPulse/blob/main/README.en.md#install), or check **Settings → Application updates** and confirm installation. Windows packages have no publisher certificate. Mac packages use ad-hoc signing without Apple notarization. Follow normal OS security confirmation as described in the [installation guide](https://github.com/qingtian-4/TaskPulse/blob/main/docs/INSTALL.en.md).

### Known limitations and remaining acceptance

- Codex approvals need an existing explicit event channel. Native Claude questions remain unsupported. Sources without a reliable return interface offer details or copy actions.
- Large real-source cohorts grouped by agent, version and platform still need accuracy, rendered P95, host-return and total-resource acceptance. Short pilots and fixed replay do not certify these results.
- Ordinary interactive MSI UAC, physical Windows ARM64, first launch and trust on both Mac architectures, high DPI, multiple monitors and actual sleep/resume need their respective hardware acceptance.
