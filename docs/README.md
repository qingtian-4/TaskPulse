# TaskPulse 使用指南

1. [安装 TaskPulse](INSTALL.md)：选择 Windows 或 Mac 安装包，也可使用一条命令安装。
2. 首次启动，确认发现的本机 Agent，点击**开始监控**。
3. 回到 Agent 开始任务，从托盘查看运行状态、模型、耗时和提醒。
